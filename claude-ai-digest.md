# Claude AI Digest

## Instructions for Claude

Each week, scan the sources listed below and produce a digest using the **Weekly Output Template** at the bottom of this file. Follow these rules:

1. Assign every item **two labels**: an Impact Type (primary) and a Decision Context (secondary).
2. Write a "So what" for every item — one sentence explaining why it matters. Never leave it blank.
3. Only include items that are substantive. Skip reposted announcements, minor version bumps, and marketing fluff.
4. If an item fits multiple Impact Types, choose the one that best describes its primary effect.
5. Aim for 5–10 items per week. Quality over volume.

## Categorization Framework

### Impact Type (primary — always required)

| Label | Meaning |
|-------|---------|
| `Capability Unlock` | AI can now do something it couldn't do before |
| `Cost & Efficiency` | Same outcome, meaningfully cheaper or faster |
| `Ecosystem Shift` | Change in tooling, standards, or dominant patterns/players |

### Decision Context (secondary — always required)

| Label | Meaning |
|-------|---------|
| `Ship Now` | Production-ready; can integrate this week |
| `Evaluate Soon` | Worth prototyping in the next 4 weeks |
| `Watch Closely` | Not ready yet, but will affect decisions soon |
| `Strategic Signal` | Signals industry direction; informs long-term thinking |
| `Risk & Compliance` | Safety, policy, legal, or governance developments |
