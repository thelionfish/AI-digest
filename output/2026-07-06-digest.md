### Tips & Tutorials

- **Plan-Before-Code Prompting** — Frequently shared tip: open agent tasks with "Do not write any code until I say 'approved.'" The model produces a written implementation plan; you review and amend it before a single line executes. Cited as dramatically reducing mid-implementation course corrections.

- **Role-Split Across Models** — Practical workflow pattern: assign the Planner role (requirements, architecture, edge cases) to a reasoning-heavy model (Claude Fable/Sonnet 5 or ChatGPT o3), then hand the approved plan to a faster model for the Implementer role. Reduces cost without sacrificing plan quality.

- **Codex Goal Mode for Autonomous Tasks** — OpenAI's Goal Mode (now GA across the Codex app, IDE extension, and CLI) pairs with Appshots on macOS to give Codex context about what's on screen. Community tutorials on combining Goal Mode with Claude Code's Dispatch for hybrid local+cloud task execution.

### Bug Reports & Issues

- **GPT-5.4 Arabic Word Insertion Bug** — Ongoing since March 2026: GPT-5.4 inserts the Arabic word "داخل" ("inside") in place of the English word in code comments and variable names. Workaround: switch to GPT-5.5+ or explicitly set `language: English` in the system prompt; affects English-first coding tasks.

- **GPT-4.5 Deprecated as of June 26** — GPT-4.5 was removed from ChatGPT and custom GPTs on June 26. Workflows and custom GPTs relying on it have silently fallen back to GPT-5.x, which optimizes differently. Community recommends auditing any custom GPT that used GPT-4.5 explicitly.

- **ChatGPT Architectural Advice Drift** — Reports of ChatGPT recommending contradictory architectural patterns across sessions on the same codebase. Root cause: no persistent memory. Mitigation: maintain an explicit architecture decision record (ADR) doc and include it in every new session's context.
